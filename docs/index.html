How to publish

This site can be published using GitHub Pages. A GitHub Actions workflow is included to deploy the `docs/` folder and the contents of `dist/` (copied into `docs/releases`) to the `gh-pages` branch when you push this branch.

  1. Push the branch `copilot/update-vscode-documentation` to GitHub.
  2. Wait for GitHub Actions to finish the `Deploy to GitHub Pages` workflow.
  3. Visit https://<your-username>.github.io/<repo-name>/ once published.

Alternative hosts: Netlify, Vercel, or upload the .exe files to any file hosting and link from here.

Generated by your local workspace — place binaries in dist/ before pushing. See docs/PUBLISHING.md for details.
