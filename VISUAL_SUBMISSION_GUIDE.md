TROUBLESHOOTING GUIDE
═══════════════════════════════════════════════════════════════════════════════

ISSUE: "Name is not available"
SOLUTION:
- Try alternative names:
  * "Autonomous Diary Pro"
  * "Personal Diary AI"
  * "Sentiment Diary"
- Check if name is already reserved
- Ensure name doesn't violate policies

ISSUE: "Package failed validation"
SOLUTION:
- Ensure AutonomousDiary.exe is properly signed
- Check Windows 10/11 compatibility
- Verify no missing dependencies
- Try rebuilding with PyInstaller

ISSUE: "Certification rejected"
SOLUTION:
- Read rejection reason carefully
- Fix identified issues
- Resubmit (no fee for resubmissions)
- Contact Microsoft Support if unclear

ISSUE: "Payment declined"
SOLUTION:
- Verify credit card is valid
- Check card security/fraud protection
- Use different payment method
- Contact Microsoft billing support

ISSUE: "File upload stuck"
SOLUTION:
- Try smaller file upload
- Use different browser (Edge, Chrome)
- Check internet connection speed
- Clear browser cache
- Try again with new upload
