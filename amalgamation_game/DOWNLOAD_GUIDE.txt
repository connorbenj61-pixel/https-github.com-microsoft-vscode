SOLUTION: Python not installed or not in PATH
  → Install Python from https://www.python.org/downloads
  → Check "Add Python to PATH" during installation
  → Restart PowerShell

PROBLEM: "ModuleNotFoundError: No module named 'tkinter'"
SOLUTION: tkinter not installed with Python
  → Windows: Reinstall Python, select "tcl/tk and IDLE" in installer
  → macOS: brew install python-tk
  → Linux: sudo apt-get install python3-tk

PROBLEM: Game won't start
SOLUTION: Check you're in correct directory
  → Verify path: C:\Users\conno\OneDrive\Personal Vault\Documents\GitHub\https-github.com-microsoft-vscode\amalgamation_game

  → Check PowerShell error messages
