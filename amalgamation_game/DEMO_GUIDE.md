🎮 WHAT IS THE DEMO?

The demo is an interactive showcase of the entire Amalgamation Game platform,
designed to demonstrate all features and capabilities.

📺 HOW TO RUN THE DEMO

Option 1 - From Terminal:
    python demo.py

Option 2 - Direct execution:
    From the amalgamation_game folder, run the demo.py file

Option 3 - From the main game:
    Launch main.py, then use the demo launch feature if available

🎯 DEMO FEATURES

The demo interface includes 5 interactive tabs:

1️⃣ PLATFORM OVERVIEW
   • Complete feature list
   • Statistics and specifications
   • Production code metrics

2️⃣ AVATAR SYSTEM
   • Royal Healer Knight character display
   • Medical specialties and tiers
   • Base stats and abilities
   • Healing inventory

3️⃣ AI OPPONENTS
   • Necromancer: 163-IQ strategic AI
   • Royal Guardian: Squad-based tactics
   • Chess 3D: Neural network chess engine
   • Detailed descriptions and strategies

4️⃣ TOURNAMENT SYSTEM
   • $10,000 prize pool breakdown
   • 5 game modes explained
   • 5 difficulty levels (Novice → Amalgamated)
   • Player progression system

5️⃣ LIVE DEMO
   • Automated match simulation
   • Turn-by-turn gameplay narrative
   • AI decision-making showcase
   • Reward and progression display
   • Results and leaderboard updates

🎬 USING THE DEMO CONTROLS

▶ START DEMO
   Click to begin the automated match simulation in the Live Demo tab.
   The demo will show a complete match from start to finish with
   narrative commentary about each turn and action.

⏹ STOP DEMO
   Click to stop the current demo sequence at any time.
   Useful if you want to explore other tabs while demo is running.

🎮 PLAY GAME
   Click to close the demo and launch the full Amalgamation Game
   with all interactive features enabled.
