# Dick Turpin Avatar (Demo)

This folder contains a safe, non-autonomous avatar model and a demo runner.

- `dick_turpin_avatar.py`: `Avatar` class with descriptive fields and a safe `self_improve` method.
- `run_avatar_demo.py`: prints description, ASCII art, trademark notice, and a sample attribute update.

Note: This is for testing and demonstration only. The trademark notice is a placeholder.
